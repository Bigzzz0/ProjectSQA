# Initial MIO suite archive

This folder preserves the first EvoSuite-generated `NumberUtils` suite committed in the `First Mio Test` change. It is retained as historical project evidence and is not part of the active MIO benchmark suites.

The active, bug-scoped suites remain under `MIO_Algorithm/TestCode/<Project>_<BugID>b/`. Do not use these archived files for benchmark evaluation unless they are independently matched to a project and bug and re-verified.
